01 · AI Production

Documentation • AI Ops

AI-Assisted Documentation Pipeline

Problem

Writers and SMEs spent review time correcting structure and formatting, and filling gaps where the draft missed or misread source content, before they could validate technical accuracy. Source material ranged from training decks and image-only files to table-heavy PDFs and code samples.

Outcome

The pipeline separates drafting decisions from controlled formatting, with SME flags, contract validation, draft QA, render QA, and traceable run logs. It supports both a human-reviewed Copilot workflow and an automated Claude Cowork implementation. A single operator ran 22 sources through the Claude pipeline in one week, producing 63 articles, splitting 10 sources and keeping 12 single based on source structure.

02 · Staging Tool

Tooling • Staging Workflow

Knowledge Article Staging Tool

Problem

Approved Word drafts still needed manual HTML cleanup before publishing. Writers stripped Word markup, rebuilt lists and tables, reapplied styles, and switched between editor, source view, and preview to catch errors. Generic HTML cleaners couldn’t match the team’s Salesforce implementation.

Outcome

A guided three-step workflow (paste, review, copy) with editable source, live preview, and pre-publication validation. A typical article now stages in about 15 minutes instead of 30–60 — formatting collapses to minutes, verification stays with the writer — with non-technical writers getting direct control over HTML output.

03 · Framework

Knowledge Ops • Team Systems

Knowledge Ops & Governance Framework

Problem

Two analysts independently drafted articles from the same source document — duplicating authoring and SME review time, the scarcest resource in the pipeline — and two new hires couldn’t get a straight answer about the team’s own process. Ownership, evidence, and review commitments existed as suggestions, not controls.

Outcome

A lifecycle of nine controlled statuses, each with entry criteria, one named owner, exit criteria, required evidence, and allowed next statuses. Review commitments split acknowledgement from decision, so busy SME reviewers are only asked what they can honor. Endorsed by the Team Lead; full rollout targeted for Q1 2027.
